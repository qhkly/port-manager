# 端口管理器

一个基于 Tauri 2 的桌面应用，用于管理系统端口和进程。

## 功能

- 实时显示所有监听端口及其占用进程
- 显示进程详细信息（PID、进程名、用户）
- 手动终止占用端口的进程
- 自动刷新功能（每 10 秒）
- 端口和进程搜索过滤

## 技术栈

- **桌面框架**: Tauri 2
- **后端**: Rust + tokio
- **前端**: React 18 + JSX
- **平台支持**: macOS + Linux

## 开发

```bash
# 安装依赖
npm install

# 启动开发模式
npm run dev

# 构建生产版本
npm run build
```

## 使用

1. 启动应用后会自动扫描所有监听端口
2. 端口列表显示端口、协议、进程名、PID 和用户信息
3. 点击"终止"按钮可以终止占用端口的进程
4. 使用搜索框可以过滤端口、进程名或命令
5. 自动刷新功能默认开启，每 10 秒更新一次
